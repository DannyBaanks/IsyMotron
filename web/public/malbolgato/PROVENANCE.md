# Malbolgato

Asset original copiado desde `avatar/packs/malbolge-cat/idle.gif` del repositorio IsyMotron.

Este launcher representa y abre el acceso preparado para GUS/chat; no concede permisos, no ejecuta acciones y no fabrica estados de autoridad.

La implementación web actual no expone todavía un endpoint de chat real. Por eso el panel informa honestamente que la conexión de chat está pendiente, en vez de simular mensajes o receipts.
