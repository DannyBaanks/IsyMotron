# IsyMotron v1.2.0-rc.2 — iOS launch fix

This release supersedes v1.2.0-rc.1. It embeds the dynamically linked `llama.framework` in the iOS app bundle, fixing launch failure on devices. The IPA remains unsigned and must be signed with your Apple ID before installation.

This release candidate brings GUS to IsyMotron Móvil for the NVIDIA hackathon. It includes sideloadable Android and iOS packages alongside the existing Windows, Linux and macOS builds. It remains a prerelease while physical-device inference, offline use, and model restore are tested.

## Mobile downloads

| Asset | Platform | Package notes |
|---|---|---|
| `IsyMotron-android-debug.apk` | Android arm64 | Debug-signed for sideloading; not a Play Store bundle. |
| `IsyMotron-ios-unsigned.ipa` | iPhone / iPad | Unsigned; sign with your Apple ID before installing. |

Both packages exclude GGUF weights. Download or import a model after installation. Verify the SHA-256 manifest and the GitHub build-provenance attestation before installing.

## GUS: local first, remote by choice

- Chat and model controls are available from **Inicio → Abrir GUS · asistente**.
- Local models are downloaded from pinned catalogue revisions or restored from an external copy exported through the system file picker. Imports are checked for their expected size and SHA-256 before activation.
- NVIDIA Nemotron 3 Nano 4B Q4_K_M is included as an experimental local option. Its GGUF is about 2.84 GB. NVIDIA lists English and code; Spanish quality and inference performance, memory use, heat and battery life on phones are **NOT_DEMONSTRATED**. IsyMotron caps the context at 2,048 tokens and responses at 160 tokens.
- NVIDIA NIM has an explicit preset for `nvidia/nemotron-3-nano-30b-a3b`. Remote inference stays off until selected; only then, when a message is sent, does the app transmit that conversation to the configured provider. No Link credentials, permissions, PC files or receipts are sent.
- Provider errors do not fall back to a different route. API keys are held in iOS Keychain or Android Keystore-backed storage.

## Verification and remaining evidence

The release workflow runs mobile unit tests, validates the pinned runtime and catalogue, builds the native packages, checks that neither package contains `.gguf` files, calculates SHA-256 checksums, and publishes build-provenance attestations. Check the linked Actions run for the exact build logs and receipts.

CI compilation is not device validation. Local offline generation, thermal behavior, backup export, uninstall/reinstall restore, and remote opt-in on physical iPhone and Android devices remain **NOT_DEMONSTRATED** until those tests are performed.

For installation and recovery details, see the [GUS mobile guide](https://github.com/DannyBaanks/IsyMotron/blob/v1.2.0-rc.2/docs/mobile/GUS_GUIDE.md).
